# IMDb Data Analysis SQL Project

# Project Overview
This project analyzes IMDb movie data using SQL to discover trends in movie genres, ratings, production companies, actors, and directors.

# Objectives
- Analyze movie release trends
- Identify top-performing genres
- Study audience ratings
- Rank actors and actresses
- Analyze directors and production companies

# Tools Used
- MySQL
- Excel

## Database Tables
- movie
- genre
- ratings
- names
- director_mapping
- role_mapping

## Key Insights
- Drama was the most common genre
- Most movies were released in March
- Movies with higher ratings received more audience votes
- Vijay Sethupathi ranked among top actors
- Taapsee Pannu ranked among top actresses

- SQL Queries
